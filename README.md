# Планка-челлендж Bot

Telegram-бот для регистрации участников, ежедневных видеоотчётов в теме форум-группы, штрафов, ручного подтверждения оплат и админской статистики.

## Быстрый старт

1. Скопируйте `.env.example` в `.env`.
2. Заполните `BOT_TOKEN`, `ADMIN_IDS`, `CHALLENGE_GROUP_ID` и `REPORT_TOPIC_ID`.
3. Поднимите базу:

```bash
docker compose up -d db
```

4. Выполните миграции:

```bash
docker compose run --rm bot alembic upgrade head
```

5. Запустите бота:

```bash
docker compose up --build
```

## Переменные окружения

- `BOT_TOKEN` — токен бота из BotFather.
- `DATABASE_URL` — async SQLAlchemy URL PostgreSQL.
- `ADMIN_IDS` — ровно два Telegram user ID через запятую.
- `CHALLENGE_GROUP_ID` — ID форум-группы.
- `REPORT_TOPIC_ID` — ID темы, куда участники присылают видео.
- `DAILY_LIST_TOPIC_ID` — ID темы, где бот публикует и закрепляет ежедневный список.
- `TIMEZONE` — по умолчанию `Europe/Moscow`.
- `DAILY_CLOSE_TIME` — по умолчанию `01:00`.
- `PENALTY_STEP_RUB` — по умолчанию `500`.
- `ENTRY_FEE_RUB` — входной платёж перед выдачей ссылки, по умолчанию `500`.
- `PAYMENT_BANK` — по умолчанию `Название банка`.
- `PAYMENT_PHONE` — по умолчанию `PHONE_PLACEHOLDER`.
- `PAYMENT_RECIPIENT` — по умолчанию `Получатель перевода`.
- `LOG_LEVEL` — уровень логирования.

## Права бота в группе

Бот должен быть администратором форум-группы и иметь права:

- создавать invite-ссылки;
- читать сообщения в группе и теме отчётов;
- отправлять сообщения;
- редактировать свои сообщения;
- закреплять сообщения;
- удалять участников.

В BotFather отключите privacy mode для бота или убедитесь, что бот как администратор получает сообщения в нужной теме.

## Как получить ID группы и темы

1. Добавьте бота в форум-группу администратором.
2. Временно отправьте любое сообщение в нужную тему отчётов.
3. Посмотрите update через отладочный webhook/logging или отдельного helper-бота.
4. `chat.id` укажите как `CHALLENGE_GROUP_ID`.
5. `message_thread_id` темы отчётов укажите как `REPORT_TOPIC_ID`.
6. `message_thread_id` главной темы со списком укажите как `DAILY_LIST_TOPIC_ID`.

## Что проверять вручную

- Регистрация участника через `/start`.
- Принятие правил, оплата входа `ENTRY_FEE_RUB` и создание одноразовой invite-ссылки после подтверждения админом.
- Вступление в группу по персональной ссылке.
- Приём обычного видео в настроенной теме.
- Отклонение дубля того же видео.
- Игнорирование видео в другой теме.
- Отправка чека участником в личку боту.
- Получение заявки двумя админами.
- Подтверждение и отклонение оплаты кнопками.
- Ежедневное создание и закрепление нового списка после `01:00 МСК`.
- Начисление долга за пропуск.
- Ежедневные напоминания о долге.
- Удаление на 4-й день просрочки.
- Повторная invite-ссылка после подтверждённой оплаты удалённого участника.
